## 🎯 Основы Cursor AI

**Cursor AI** — это интегрированная среда разработки (IDE) с встроенным AI-ассистентом, который помогает:
- Писать код быстрее и эффективнее
- Находить и исправлять ошибки
- Генерировать код по описанию
- Оптимизировать существующий код
- Добавлять комментарии и документацию

### Поддерживаемые модели:
- OpenAI GPT-4
- Azure OpenAI
- Локальные LLM модели

## 🔧 Команды @ и @/

### Команда @
Используется для **ссылки на контекст и файлы**:

#### Основные варианты:
- `@filename` - ссылка на конкретный файл
- `@folder` - ссылка на папку
- `@code` - ссылка на выделенный код
- `@docs` - ссылка на документацию
- `@web` - поиск в интернете

#### Примеры использования:
```
@package.json - покажи зависимости в этом файле
@src/components - проанализируй все компоненты в этой папке
@README.md - объясни содержимое этого файла
@web - найди информацию о React hooks
```

### Команда @/
Используется для **навигации по проекту**:

#### Основные варианты:
- `@/` - показать структуру проекта
- `@/folder` - показать содержимое папки
- `@/file` - открыть конкретный файл

#### Примеры использования:
```
@/ - покажи структуру моего проекта
@/src - покажи что в папке src
@/package.json - открой package.json
```

## 🎯 Советы и лучшие практики

### ✅ Что делать:
1. **Будьте конкретными** - четко описывайте что вам нужно
2. **Используйте контекст** - ссылайтесь на файлы с помощью @
3. **Задавайте уточняющие вопросы** - если ответ неполный
4. **Экспериментируйте** - пробуйте разные формулировки промптов
5. **Сохраняйте лучшие промпты** - создавайте свою коллекцию

### ❌ Чего избегать:
1. **Слишком общих запросов** - "сделай код лучше"
2. **Отсутствия контекста** - не указывать какие файлы анализировать
3. **Неконкретных требований** - "сделай красиво"
4. **Игнорирования ошибок** - всегда проверяйте сгенерированный код

### 🔥 Продвинутые техники:

#### 1. Цепочка промптов:
```
1. Сначала: "Проанализируй архитектуру этого проекта"
2. Затем: "Предложи улучшения на основе анализа"
3. Наконец: "Реализуй предложенные улучшения"
```

#### 2. Ролевое моделирование:
```
Ты опытный архитектор ПО. Проанализируй этот код и предложи архитектурные улучшения.
```

#### 3. Контекстное программирование:
```
@database.js @models.js - создай API endpoints для CRUD операций с этими моделями
```
