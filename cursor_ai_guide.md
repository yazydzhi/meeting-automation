## 🎯 Основы Cursor AI

**Cursor AI** — это интегрированная среда разработки (IDE) с встроенным AI-ассистентом, который помогает:
- Писать код быстрее и эффективнее
- Находить и исправлять ошибки
- Генерировать код по описанию
- Оптимизировать существующий код
- Добавлять комментарии и документацию

### Поддерживаемые модели:
- OpenAI GPT-4
- Azure OpenAI
- Локальные LLM модели

## 🔧 Команды @, @/ и /

### Команда @
Используется для **ссылки на контекст и файлы**:

#### Основные варианты:
- `@filename` - ссылка на конкретный файл
- `@folder` - ссылка на папку
- `@code` - ссылка на выделенный код
- `@docs` - ссылка на документацию
- `@web` - поиск в интернете

#### Примеры использования:
```
@package.json - покажи зависимости в этом файле
@src/components - проанализируй все компоненты в этой папке
@README.md - объясни содержимое этого файла
@web - найди информацию о React hooks
```

### Команда @/
Используется для **навигации по проекту**:

#### Основные варианты:
- `@/` - показать структуру проекта
- `@/folder` - показать содержимое папки
- `@/file` - открыть конкретный файл

#### Примеры использования:
```
@/ - покажи структуру моего проекта
@/src - покажи что в папке src
@/package.json - открой package.json
```

### Команда /
Используется для **вызова пользовательских команд и функций**:

#### Встроенные команды:
- `/new` - создать новый файл или проект
- `/open` - открыть существующий файл или проект
- `/settings` - открыть настройки приложения
- `/help` - вызвать справку или документацию

#### Пользовательские команды:
Создавайте собственные команды в папке `.cursor/commands/`:

**Структура:**
```
.cursor/
└── commands/
    ├── review-code.md
    ├── write-tests.md
    └── setup-new-feature.md
```

**Пример пользовательской команды (`review-code.md`):**
```markdown
# Чек-лист код-ревью

## Функциональность
- [ ] Код выполняет заявленные функции
- [ ] Обработаны крайние случаи
- [ ] Корректная обработка ошибок

## Качество кода
- [ ] Код читаемый и хорошо структурирован
- [ ] Имена переменных информативны
- [ ] Нет дублирования кода
```

#### Примеры использования:
```
/review-code - запустить процесс ревью кода
/write-tests - сгенерировать тесты для кода
/create-pr - создать pull request
```

## 🚀 Другие полезные возможности Cursor AI

### ⌨️ Горячие клавиши и быстрые действия

#### Основные горячие клавиши:
- `⌘ K` (Mac) / `Ctrl K` (Windows/Linux) - **Быстрые вопросы** - мгновенные ответы о выделенном коде
- `⌘ L` (Mac) / `Ctrl L` (Windows/Linux) - **Открыть чат** с AI
- `Tab` - **Автодополнение** - принять предложение AI
- `Esc` - **Отклонить** предложение AI
- `⌘ I` (Mac) / `Ctrl I` (Windows/Linux) - **Composer** - режим генерации кода

#### Быстрые вопросы (⌘ K):
```
Выделите код → ⌘ K → "Объясни этот алгоритм"
Выделите код → ⌘ K → "Найди ошибки в этом коде"
Выделите код → ⌘ K → "Оптимизируй производительность"
```

### 🎭 Режимы работы

#### 1. **Agent** - Автономный режим
- **Назначение:** Сложные задачи и рефакторинг
- **Возможности:** 
  - Автономно исследует кодовую базу
  - Редактирует несколько файлов одновременно
  - Исправляет ошибки
  - Выполняет команды в терминале

**Пример использования:**
```
"Добавь аутентификацию пользователей в это приложение"
```

#### 2. **Ask** - Режим вопросов
- **Назначение:** Обучение и планирование
- **Возможности:**
  - Исследует код без изменений
  - Отвечает на вопросы
  - Планирует архитектуру
  - Объясняет сложные концепции

**Пример использования:**
```
"Как работает эта архитектура микросервисов?"
```

#### 3. **Manual** - Ручной режим
- **Назначение:** Точные правки
- **Возможности:**
  - Редактирует только выбранные файлы
  - Полный контроль над изменениями
  - Без автоматических действий

**Пример использования:**
```
"Исправь только эту функцию, не трогая остальной код"
```

#### 4. **Custom** - Пользовательский режим
- **Назначение:** Специализированные рабочие процессы
- **Возможности:**
  - Создание собственных режимов
  - Настройка инструментов
  - Определение инструкций

### 💬 Интерактивный чат

#### Особенности чата:
- **Контекстное понимание** - знает текущий файл и позицию курсора
- **Мгновенное применение** - предложения можно применить одним кликом
- **Визуальный контекст** - поддержка изображений и диаграмм
- **Сохранение истории** - все беседы сохраняются

#### Примеры использования чата:
```
"Создай компонент React для модального окна"
"Объясни этот алгоритм сортировки"
"Найди все места, где используется эта функция"
"Создай диаграмму архитектуры этого проекта"
```

### 🖥️ Интеграция с терминалом

#### Возможности:
- **Естественный язык** - вводите запросы на русском/английском
- **Автоматический перевод** - в команды терминала
- **Выполнение команд** - AI может выполнять команды самостоятельно
- **Отслеживание вывода** - AI анализирует результаты

#### Примеры:
```
"Найди все файлы, измененные за последние 24 часа"
"Установи зависимости для этого проекта"
"Запусти тесты и покажи результаты"
"Создай новую ветку для функции аутентификации"
```

### 📁 Работа с несколькими проектами

#### Возможности:
- **Объединение проектов** - несколько папок в одном рабочем пространстве
- **Быстрое переключение** - между проектами в один клик
- **Общий контекст** - AI понимает связи между проектами

#### Настройка:
1. Создайте рабочее пространство
2. Добавьте нужные папки
3. Настройте быстрый доступ
4. Переключайтесь между проектами

### 💾 Сохранение и экспорт

#### Возможности:
- **Экспорт чатов** - в формате Markdown
- **Сохранение бесед** - для последующего использования
- **Обмен с коллегами** - отправка файлов
- **Настройка отображения** - размер шрифта и форматирование

#### Как использовать:
1. В чате выберите функцию экспорта
2. Сохраните в нужном формате
3. Отправьте коллегам или используйте для отчетности

### 🎨 Composer - Режим генерации кода

#### Возможности:
- **Генерация кода** - по описанию на естественном языке
- **Редактирование** - изменение существующего кода
- **Создание файлов** - новые компоненты и модули
- **Рефакторинг** - улучшение структуры кода

#### Активация:
- `⌘ I` (Mac) / `Ctrl I` (Windows/Linux)
- Или через меню "Composer"

#### Примеры:
```
"Создай React компонент для формы регистрации с валидацией"
"Добавь обработку ошибок в этот API endpoint"
"Рефактори этот класс, используя паттерн Observer"
```

## 🎯 Советы и лучшие практики

### ✅ Что делать:
1. **Будьте конкретными** - четко описывайте что вам нужно
2. **Используйте контекст** - ссылайтесь на файлы с помощью @
3. **Задавайте уточняющие вопросы** - если ответ неполный
4. **Экспериментируйте** - пробуйте разные формулировки промптов
5. **Сохраняйте лучшие промпты** - создавайте свою коллекцию
6. **Используйте горячие клавиши** - ⌘ K для быстрых вопросов
7. **Выбирайте правильный режим** - Agent для сложных задач, Manual для точных правок
8. **Создавайте пользовательские команды** - автоматизируйте повторяющиеся задачи
9. **Экспортируйте важные беседы** - сохраняйте полезные обсуждения
10. **Используйте Composer** - для генерации больших блоков кода

### ❌ Чего избегать:
1. **Слишком общих запросов** - "сделай код лучше"
2. **Отсутствия контекста** - не указывать какие файлы анализировать
3. **Неконкретных требований** - "сделай красиво"
4. **Игнорирования ошибок** - всегда проверяйте сгенерированный код
5. **Использования Agent для простых задач** - выбирайте Manual для точных правок
6. **Забывания о горячих клавишах** - ⌘ K намного быстрее чем чат
7. **Игнорирования пользовательских команд** - создавайте их для частых задач

### 🔥 Продвинутые техники:

#### 1. Цепочка промптов:

```
1. Сначала: "Проанализируй архитектуру этого проекта"

```
